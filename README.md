# TaskFlow

TaskFlow is a simple Kanban-style task management web app built with HTML, CSS, and JavaScript. It helps users organize work by splitting tasks into three stages: To Do, In Progress, and Done.

## What this project does

- Add new tasks with a title and description
- Display tasks in a board layout
- Drag and drop tasks between columns
- Delete tasks when they are no longer needed
- Save task data in the browser using localStorage so the board remains available after refresh
- Show the number of tasks in each column

## Features

- Clean and simple user interface
- Interactive Kanban workflow
- Persistent task data in the browser
- Easy task management for daily planning and productivity
